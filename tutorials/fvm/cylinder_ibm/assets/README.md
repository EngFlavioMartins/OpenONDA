# Immersed-cylinder diagnostics

The [case guide](../README.md) defines marker spacing, Reynolds number, the forcing Fourier limit and run commands. See [FVM boundary conditions](../../../../docs/fvm.md#boundary-conditions) for immersed forcing.

`mesh_rectilinear.py` builds the graded grid. `plot_forces.py` plots drag, lift and marker slip; `plot_wake.py` estimates recirculation length; `plot_fields.py` shows velocity and vorticity.
