# Audit source notes

Status: historical pre-tightening audit. The report's numerical rankings apply
only to the old runs/configuration; its principal diagnostic and configuration
findings have since been implemented in the tutorial.

Audience: technical. Delivery mode: portable HTML.

Required technical-report roles map as follows:

- Technical summary: `technical_summary`
- Key findings with visual evidence: `why_stop`, `merging_endpoints`, `field_validation`, `vorticity_profile_error`
- Scope, data, and metric definitions: `definitions`, `measurement_limits`
- Methodology: canonical source metadata on `derived_audit`
- Limitations, uncertainty, and robustness: `robustness`
- Recommended next steps: `next_steps`
- Further questions: `further_questions`

Chart map:

1. `merging_endpoints`: grouped category bar; question is when each observable becomes unavailable; source fields are scheme, last valid core tau, last valid pair tau, first merged tau, final simulation tau, and validity fractions. Two-root palette distinguishes estimator types. The chart intentionally excludes RWM because its long endpoint is generated by false stochastic peaks and is not comparable.
2. `vorticity_profile_error`: single-series category bar; question is which current configurations reproduce the isolated-vortex vorticity profile; source fields also retain velocity/gradient errors, correlation, time, and core-radius error for audit. A single orange root is used; exact multi-metric lookup is in the adjacent table.

Omitted visual:

- The energy-budget results are described narratively rather than charted because finite-difference `dE/dt`, instantaneous `-nu*Omega`, analytic t=0 insertion, and discrete grid remeshing do not yet form a like-for-like validation metric.
- No replacement for the user's established benchmark figures was created. The report charts are audit-only evidence and do not change the existing figure templates.

Important interpretation constraints:

- The reported single-vortex errors compare a finite 3-D column sampled at z=L/4 with an infinite 2-D analytic solution, so the shared CS/GBD velocity-error floor includes model-form error.
- Literature core-radius and time-coordinate definitions require direct reconstruction before quantitative scoring.
- RWM's single realization is assessed for adequacy of the current benchmark, not as a rejection of the converged random vortex methodology.
