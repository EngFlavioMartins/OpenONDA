# Reference-flow mesh assets

`cylinder_preview.vtu` is the qualified D/24 mesh produced by
`openonda.fvm.mesher.CartesianMesher`. It contains 512,404 native control
volumes: 475,316 VTK hexahedra in the Cartesian/layer core and 37,088 VTK
polyhedra where cut-cell or octree-transition topology requires them. It is
not generated by Gmsh, an O-grid, or a geometry-specific mesher.

The mesh has two named volume-refinement regions and ten continuous layers on
the STL wall. The first requested wall-normal height is D/384 (`dx/16`) and
the growth ratio is 1.15. Numerical qualification, hashes, requested/effective
sizes, layer measurements, patch areas, and quality extrema are recorded in
`cylinder_mesh_report.json`. `cylinder_preview.png` shows the true midspan
polygon edges; renderer-internal triangulation diagonals are intentionally
excluded.

To inspect it in ParaView:

1. Open `cylinder_preview.vtu` and click **Apply**.
2. Colour by `cell_family` (`0` = native hexahedron, `1` = polyhedron),
   `refinement_region`, or `boundary_layer_index` (`-1` = core, `0..9` =
   wall layers).
3. Apply a **Slice** with normal `(0, 0, 1)` at the origin and choose
   **Surface With Edges**.

Useful cell arrays also include `cell_size`, `refinement_level`,
`cell_volume`, `cell_max_nonorthogonality_deg`, and `cell_max_skewness`.
