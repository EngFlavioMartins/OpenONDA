# Cartesian mesher Phase 0: contract freeze and gap audit

*Date: 2026-09-02*

*Status: Phase 0 audit artifacts are complete. The red test count below is the
historical pre-implementation baseline; later phase tests now exercise the
typed adapter and native build.*

## Scope

This phase freezes the target contract from [`mesher_project.md`](../../../mesher_project.md),
records the current implementation as baseline evidence, and adds tests for
the geometry-independent public API and acceptance-matrix entry points. It
does not rewrite the existing meshing algorithms.

The branch was not changed. The audit started at `e9d7da4e`; the worktree
already contained user changes deleting `solver_verification.xml` and editing
`tutorials/coupled_fvm_vpm/cylinder_shedding_flow/reference_flow/setup.py`.
Neither file was modified by this phase.

## Files added

* `docs/architecture/adr-cartesian-mesher.md` freezes the one-mesher decision,
  stage boundaries, rejected alternatives, and consequences.
* `source/solvers/fvm/mesh/THIRD_PARTY_NOTICES.md` records cfMesh inspiration,
  named authors, exact source links, and the fact that no upstream source was
  copied in Phase 0.
* `docs/verification/cartesian_mesher/baseline_reports.json` records two small
  native builds, their topology/quality/projection metrics, requested and
  effective sizes, and input STL hashes.
* `tests/fvm/cartesian_acceptance_fixtures.py` provides deterministic test-side
  surface fixture generation. It is independent of production meshing code.
* `tests/fvm/test_cartesian_mesher_phase0.py` adds the target export,
  architecture, and geometry-independence contract tests. These tests are
  expected to fail until the corresponding implementation phases land.

The user-provided `mesher_project.md` remains in the worktree as the governing
specification.

## Baseline commands and results

The current targeted regressions were run with the working Python interpreter:

```text
python -m pytest -q tests/fvm/test_curved_cylinder_mesh.py \
    tests/fvm/test_general_body_mesh.py tests/test_public_api.py
8 passed, 1 warning
```

The shell `pytest` launcher was not usable in this environment because it
pointed at an interpreter without pytest; `python -m pytest` is the exact
replacement command used above.

The two reports in [`baseline_reports.json`](baseline_reports.json) were
generated by constructing the current `AdaptiveCartesianMesher`, calling
`build()`, `validate_topology()`, `compute_mesh_geometry()`, and
`validate_geometry()`. Both builds passed those current checks. Their results
are historical observations, not desired golden output:

| Baseline | Cells | Faces | Patches | Min volume | Max non-orthogonality | Max skewness | Max aspect ratio | Projection |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- |
| cylinder curved projection | 3,760 | 13,068 | 7 | 1.953125e-3 | 29.7744° | 0.203548 | 3.31101 | 1,312/1,312 accepted |
| axis-aligned cube | 600 | 2,100 | 2 | 1.5625e-2 | 25.2394° | 0.142134 | 1.22474 | not used |

The cylinder report also records a maximum requested projection displacement
of `0.20710678118693468` and zero rejected points. This is precisely the
behavior that later phases must replace with a general transactional surface
recovery proof; it must not be treated as certification of arbitrary curved
surfaces.

The input SHA-256 values are recorded in the JSON report. The build command
does not write to either STL, so the hashes are unchanged by this audit.

## Licence decision gate

The repository's `license` file contains only a short GPL heading while the
package metadata and mesher documentation refer to GPL-3.0-or-later. This phase
does not replace it because the specification requires maintainer confirmation
of the intended complete licence text. No direct cfMesh code was copied or
translated, so no derivative-code notice is asserted. Before Phase 1/2 code is
merged, the maintainer must confirm the licence text and the exact upstream
study commit; then `THIRD_PARTY_NOTICES.md` must be updated with file-level
provenance for any translated material.
